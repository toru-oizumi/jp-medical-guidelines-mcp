# data/ に含まれるデータについて

このディレクトリのデータは、日本国政府が公表しているガイドライン（PDF・Excel）を
機械可読な JSON に**編集・加工**したものです。国が作成したものではありません。

## 出典

- 出典：厚生労働省ホームページ「医療情報システムの安全管理に関するガイドライン 第7.0版（令和8年6月）」
  <https://www.mhlw.go.jp/stf/shingi/0000516275_00006.html>
- 出典：経済産業省ホームページ「医療情報を取り扱う情報システム・サービスの提供事業者における安全管理ガイドライン 第2.0版（令和7年3月改定）」
  <https://www.meti.go.jp/policy/mono_info_service/healthcare/teikyoujigyousyagl.html>

取得日・取得元 URL・各ファイルの SHA-256 は `data/sources.json` を参照してください。

## 加工の内容

- PDF からテキストを抽出し、見出し単位に分割した
- Excel のチェックリストを行単位の JSON に変換した
- 本文の文言そのものは改変していないが、抽出処理の性質上、
  レイアウト・図表・脚注は失われている、または不完全である

## 利用上の注意

- **本データは一次情報ではありません。** 条文の解釈・準拠可否の判断には、
  必ず上記の掲載ページから原本 PDF を参照してください。
- 本データおよび本ソフトウェアは、ガイドラインへの準拠を保証するものではありません。
- 厚生労働省ホームページ利用規約では、編集・加工した情報を、あたかも国が作成したかのような
  態様で公表・利用することを禁じています。本データを再配布する場合は、この注意書きを添えてください。
